# Приложение для анализа транзакций

## Описание проекта

Приложение для анализа транзакций из Excel-файлов. Программа генерирует JSON-данные для веб-страниц, формирует Excel-отчеты и предоставляет дополнительные сервисы для обработки финансовых данных.

## Функциональные возможности

- Загрузка и парсинг Excel-файлов (xlsx, xls) с транзакциями
- Генерация JSON-данных для веб-страниц
- Формирование Excel-отчетов по результатам анализа
- Анализ транзакций по категориям, датам и суммам
- Экспорт результатов в форматах JSON, Excel, CSV

## Технологии

- Python 3.14
- pandas — обработка и анализ данных
- openpyxl / xlrd — работа с Excel-файлами
- json — генерация JSON-данных
- argparse — обработка аргументов командной строки
